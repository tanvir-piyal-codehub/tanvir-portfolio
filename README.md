## 🚀 Quick Start (Local Development)

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (version 18 or newer recommended).

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/tanvir-piyal-codehub/tanvir-portfolio.git

# 2. Navigate to project directory
cd tanvir-portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:5173` or `http://localhost:3000` in your browser.

## 🌐 Deploy to Vercel in 2 Minutes

### Option 1: Via GitHub & Vercel Dashboard (Recommended)

1. Go to [Vercel](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** > **"Project"**.
3. Import your repository: `tanvir-piyal-codehub/tanvir-portfolio`.
4. Vercel will automatically detect **Vite**:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **"Deploy"** — your live site will be ready in under 60 seconds with automatic HTTPS and continuous deployment on every git push!
